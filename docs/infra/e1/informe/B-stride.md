# Anexo B. Modelo de amenazas STRIDE (AM-01…AM-18)

Cada amenaza indica la zona o activo afectado y su categoría STRIDE: suplantación (S), manipulación (T), repudio (R), divulgación de información (I), denegación de servicio (D) y elevación de privilegios (E). También indica el control que la mitiga, el control de ISO/IEC 27002:2022 que corresponde, los componentes donde se aplica y la prueba que lo valida.
